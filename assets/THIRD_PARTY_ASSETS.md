# Third-Party Assets

## Poly Haven `wooden_spoon`

Active files:

- `spoon_convexdecomposition_collision.usda`
- `wooden_spoon_visual.usdc`

The active spoon render mesh is Poly Haven's `wooden_spoon` by Ronnie Barter.
Poly Haven distributes this asset under the
[CC0 1.0 Universal license](https://polyhaven.com/license).

- Project: https://polyhaven.com/a/wooden_spoon
- Source file: `wooden_spoon_1k.usdc`
- Source MD5: `1b98fc35adacb3ed621d53c3f8a3f665`
- Project copy MD5: `9ba8faf58f9eac61587b6a66e3ff8662`

The active wrapper applies convex decomposition to the original render mesh
under a 0.06 kg rigid body. Runtime material binding replaces the source wood
material with the project's single-color matte blue print material. The project
copy removes the original material graph and external texture references, but
does not alter the source mesh geometry or authored normals.
